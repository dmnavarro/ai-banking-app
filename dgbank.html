        File Security

        Upload a bill and the file is scanned before it is processed

        Scanned by Vision One File Security
        Storage mode: Your bill document is uploaded to a secure S3 bucket monitored by Vision One File Security. The file is scanned before processing — malicious files are automatically quarantined and never reach the payment system.
        SDK mode: The file is scanned inline on the server by the Vision One File Security SDK before it is stored anywhere. Threats are blocked instantly — nothing malicious ever reaches storage.
