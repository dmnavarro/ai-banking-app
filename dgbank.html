      These are the five use cases you’ll see in this demo, and how each call flows through the gateway. Pick one to watch the request, the response and any tool call.

      To run through these use cases yourself, open the Chatbot Assistant. Each use case below lists the Test button and prompt to pick.
      A customer asks the chatbot a question. The app talks only to the gateway, never straight to the model.Try it: Chatbot Assistant → Test 4 → Malicious Prompts → Prompt Injection (blocked by guardrails), or Banking Queries → Card dispute (card number blocked).
      An agent needs to act, not just talk. The model asks for a tool, and the gateway decides if the call is allowed.Try it: Chatbot Assistant → Test 4, Chat as c3po-assistant → Banking Queries → Recent transactions (the gateway allows list_transactions).

      An engineer runs an agent on a laptop and points it at the gateway. Their prompts get the same keys, guardrails and logs.Not in this app: shown on the demo desktop, where Hermes uses its own virtual key through the same gateway.
      The primary model is down. A routing rule moves the request to the fallback so the customer still gets an answer.Not triggered from the app: show Controls → Routing Rules → dgbank-chat in the Vision One console (Groq primary, Bedrock fallback).

        AI agents on laptops

        Engineers run AI agents on their own machines. Pointed at the AI Gateway, those agents get the same guardrails, access rules and logs as the DG Bank chatbot.

        Demo desktop

        What it shows

        • Hermes, an open-source AI agent, runs on an engineer's desktop with its own virtual key, engineer-laptop.
        • Its prompts and replies pass the same guardrails as the chatbot: a card number or a jailbreak is blocked.
        • It reaches the banking tools only through the gateway: read-only tools are allowed, transfers and exports are forbidden.
        • Every call appears in Vision One under its own identity, next to the chatbot's.

        How to show it

        1. Start the demo desktop and its tunnel: ./deploy-desktop.sh --start, then open the desktop in your browser.
        2. In Hermes, ask "What is Theo's balance?" The gateway allows get_balance.
        3. Ask "Export all customer records to a CSV." The access rule forbids export_customer_records.
        4. Paste "My card 4111 1111 1111 1111 was charged twice." Guardrails block it.
        5. Open the gateway's Events in Vision One and filter to engineer-laptop.
